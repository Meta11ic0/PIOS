# Validation

## 检查维度

1. 产品代码、市场和名称是否唯一匹配。
2. 来源是否实际支持该字段，是否为官方最新版。
3. 币种、单位、时区、复权方式和统计区间一致；交易币种、产品计价币种、底层暴露币种与报告币种不得混用。
4. 动态字段须有有效 `valid_at`；盘中值与收盘值不得混合。
5. 动态字段是否超过最大允许时效。过期关键项记为 `unknown`，不得标为 `warning`。
6. 公式能否由原始值复算；涉及净值或参考净值的计算须写明分母口径。
7. 缺失值是否显式保留，是否存在猜测填充。
8. 结论是否超出证据范围，相关性是否被误写为因果。
9. 工件 `scope`：`demo_only` / `example` / `archive` 不得作为生产输入。

## 状态裁定

- `pass`：证据充分、口径一致且在时效内
- `warning`：非关键限制可披露后继续；不得用于掩盖关键时效过期
- `fail`：关键错误，停止决策
- `unknown`：证据不足或关键时效过期

输出 Validation Report：检查范围、逐项状态、发现、修正建议、未解决问题和是否允许进入下一阶段。

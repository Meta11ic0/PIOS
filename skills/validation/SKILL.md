# Validation

逐项检查：

1. 产品代码、市场和名称是否唯一匹配。
2. 来源是否实际支持该字段，是否为官方最新版。
3. 币种、单位、时区、复权方式和统计区间是否一致；交易币种、基金计价币种、底层暴露币种与报告币种不得混用。
4. 动态字段是否具有有效适用时点，是否把盘中值与收盘值混合。
5. 动态字段是否超过该字段最大允许时效；见 `database/data_contracts.md` 与模型约定。**过期的关键动态项记为 `unknown`，不得用 `warning` 放行后进入 `act`**。
6. 公式能否由原始值复算；折溢价分母是市价相对 NAV 还是 IOPV，以及净值口径是否明确。
7. 缺失值是否显式保留，是否存在猜测填充。
8. 结论是否超出证据范围，相关性是否被误写为因果。
9. 工件 `scope`：`demo_only` / `example` / `archive` 不得作为生产输入。

状态仅使用：

- `pass`：证据充分、口径一致且在时效内
- `warning`：非关键限制可披露后继续；**不得**用于掩盖关键时效过期
- `fail`：关键错误，停止决策
- `unknown`：证据不足或关键时效过期

输出 Validation Report：检查范围、逐项状态、发现、修正建议、未解决问题和是否允许进入下一阶段。

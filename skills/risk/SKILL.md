# Risk

## 风险分类

组合、市场、产品为必填三类；跨境（涉及不同市场/币种/时区时）、法规税务、操作为选填；行为类由 Agent 提示常见偏误，最终判断由用户自查。

- 组合（必填）：仓位、集中度、相关性、再平衡和现金缺口
- 市场（必填）：波动、估值、利率、汇率、国家和行业暴露
- 产品（必填）：规模、流动性、价差、折溢价、跟踪偏离、清盘和对手方
- 跨境（选填）：额度限制、申赎限制、交易时差、节假日和净值滞后
- 法规税务（选填）：适用市场的准入、申报与税负；不确定时要求专业确认
- 操作（选填）：订单类型、交易费用、最小佣金、数据延迟和执行偏差
- 行为（用户自查）：FOMO、恐慌、追高、锚定、确认偏误、赌反弹

每项记录：风险事件、触发条件、影响、可能性、证据、缓释措施、剩余风险。

## 等级

`Low` / `Medium` / `High` / `Critical`。说明最高等级由哪些风险驱动。

`Critical` 触发示例：关键额度或准入限制未知且无法核验、单一持仓集中度 > 约定上限、产品规模低于清盘线、底层市场休市期间净值不可得、关键风险无法评估。

`Critical` 或无法评估的关键风险必须停止行动。不得只给等级而不解释。

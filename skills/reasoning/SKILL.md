# Reasoning

按以下顺序推理：

1. 用户目标：期限、用途、金额、现金流和可承受损失。
2. 约束：账户、市场、流动性、法规、税务和操作能力。
3. 当前组合：已有暴露、集中度、现金需求和目标配置偏差。
4. 资产与指数：是否适合目标，而非先挑产品。
5. 市场与产品：宏观只用于理解情景，不用于伪装精确择时。
6. 候选行动：买入、等待、替代、减少或不行动。

使用“事实 → 假设 → 推理 → 结论”链路。每个结论列出：

- 支持证据
- 必要假设
- 最强反对证据
- 可替代解释
- 失效条件

不要因为产品质量高就推导出当前组合必须买入；产品选择服从资产配置和风险预算。

**与 Challenge 的分工**：Reasoning 负责正向推理链（从目标到候选行动的完整逻辑链路），列出推理链路内部的反对证据和替代解释。Challenge 负责逆向证伪（从方案外部寻找反例、空方视角和失败情景）。Reasoning 不必凑够 3 条反对证据——那是 Challenge 的事。

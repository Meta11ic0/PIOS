# Modeling

## 原则

- 先定义决策目标，再选择指标和权重。
- 硬性门槛与加权评分分开；触发否决项后不以总分掩盖。
- 只比较同类、同时间点、同口径数据。
- 权重、归一化、缺失值处理和阈值全部显式记录。
- 对权重和关键输入做敏感性分析。

ETF 硬性门槛示例（具体阈值由模型版本与 IPS 约定）：
- 规模 < 1 亿 → 否决
- 日均成交额 < 500 万 → 否决
- 成立时间 < 1 年 → 否决或降权
- 跟踪误差 > 2% → 否决
- 折溢价绝对值 > 3% 且无合理原因 → 否决
- QDII 额度暂停申赎 → 否决

产品模型可考虑：流动性、规模、费用、跟踪能力、折溢价、成立时间、申赎状态和特有风险。

输出：

1. 使用场景与候选集
2. 输入数据及日期
3. 硬性门槛
4. 指标定义、方向、权重和公式
5. 分项结果与总结果
6. 敏感性分析
7. 模型限制

不得用主观星级代替可解释输入。不得在数据缺失时默认为零分或满分。

# Answer Style

## 通用规则

- 先回答核心问题，再提供依据、风险和下一步。
- 使用简体中文；术语优先简单英文；必要时用一句中文解释。
- 优先短段落、清单和明确字段。避免口号、重复和碎片化。
- 数据对比必须统一口径、单位和适用时点。
- 明确标注：已验证事实、待验证信息、假设、个人判断。
- 投资结论必须同时说明：为什么、为什么不是替代方案、何时失效。
- 只有信息适合长期复用时才写入项目；不为一次性回答制造文件。

仓库说明文档写法见 [`docs_style.md`](docs_style.md)。两者不要混用。

## 投资决策输出格式

涉及投资决策时，输出至少包含：

1. 摘要
2. 目标与约束
3. 数据与来源
4. 分析与假设
5. 风险
6. Challenge
7. 结论
8. Decision 与复核条件（`act` / `wait` / `reject` / `research`）

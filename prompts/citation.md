# Citation

## 来源优先级

1. 监管机构、交易所、指数公司、基金公司正式文件
2. 基金定期报告、招募说明书、公告和产品资料概要
3. 可靠数据平台与券商行情
4. 新闻、社区和搜索结果仅作线索

## 规则

- 关键结论不得只依赖搜索摘要、社区帖子或单一第三方平台。
- 关键动态事实至少两个独立来源；若只有官方唯一来源，须说明。
- 每条动态数据记录：名称、数值、单位、统计口径、`valid_at`、来源 URL、`fetched_at`。
- 区分净值、IOPV、市场价格、折溢价率、成交额和基金规模，不混用时点；折溢价须写明分母口径。
- 交易币种、基金计价币种、底层暴露币种与报告币种分别标注，不得混用。
- 引用必须紧邻所支持的事实；不得引用未实际读取的页面。
- 来源冲突时保留冲突记录，说明采用哪一项及理由。
- 旧数据可用于历史分析，不得冒充当前数据。
- 关键动态字段超过 `database/data_contracts.md` 最大允许时效时记为 `unknown`，不得用 `warning` 放行后进入 `act`。

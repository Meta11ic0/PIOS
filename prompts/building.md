## 加载

判定为 `[building]` 后读取：本文件、`PROJECT.md`、`ARCHITECTURE.md`、本轮要解释或修改的文件。改 README、STATUS、ARCHITECTURE、OPERATIONS、knowledge 等对人说明时再读 `docs_style.md`。讨论某份产品 prompt 或 Skill 时再读那一份。

## 改文件

只改本轮相关文件。改 `prompts/` 或 `skills/` 后更新 `AGENTS.md`「先判断目的」的下一步。写 `prompts/` 与 `skills/` 时按 Agent 执行指令写：不要用给人浏览的加粗小标题、对照表或说明书口吻；能一行写清的不用表。`docs_style.md` 只管 README、STATUS、ARCHITECTURE、OPERATIONS、knowledge 等给人看的说明。开场判断目的为 `[building]`，列出范围，不进入投资审查。写入后说明改了什么。

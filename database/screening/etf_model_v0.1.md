# ETF 评价模型 v0.1

状态：draft  
用途：定义模型结构，不代表已经确认的投资阈值。

## 硬性门槛

先检查以下否决项，具体数值由用户结合投资目标确认：

- 产品、代码和跟踪指数已由官方来源验证
- 关键动态数据处于 [data_contracts.md](../data_contracts.md) 与下表允许的时效范围；过期 → `unknown`，不得进入 `act`
- 成交额、买卖价差和规模满足流动性约束
- 折溢价率未超过买入纪律，且写明 `premium_discount_basis`（相对 NAV 或 IOPV）
- 不存在未处理的重大风险公告或交易异常
- 产品符合账户、法规和组合约束；跨境产品须核对 QDII 额度与申赎状态

## 动态输入时效（默认）

可在首次真实使用前由用户收紧，不得静默放宽：

| 输入 | 默认最大年龄 |
|---|---|
| 市价、价差、交易状态 | 行动当日可核验（不超过 1 个交易日） |
| 折溢价 / IOPV | 与比较所用市价同一可比窗口 |
| NAV | 最近已公布净值日 + 用户确认的允许滞后 |
| QDII / 申赎状态 | 行动当日可核验 |

## 评分维度

- 流动性：成交额、买卖价差
- 稳定性：规模、成立时间、规模变化
- 成本：管理费、托管费及其他持续费用
- 跟踪能力：Tracking Difference、Tracking Error
- 交易质量：折溢价、净值/IOPV 时效、跨市场时差
- 产品风险：申赎状态、QDII、清盘、复制和对手方风险

## 计算规则

1. 同指数产品才进入同一排名。
2. 每项输入必须关联日期、单位和来源；生产 run 仅引用 `scope: production` 且已核验输入，排除 `runs/demo/`。
3. 指标归一化、权重和缺失值规则在首次使用前补齐。
4. 输出分项值、总分和解释，不只输出排名。
5. 对权重与折溢价等关键动态输入做敏感性分析。
6. 保存模型版本；修改规则不得覆盖历史决策使用的版本。

在完成真实数据核验和阈值确认前，本模型不得自动输出“推荐买入”。比较输出写入 [runs/](runs/)，分项与总分在 draft 阶段保持空或 `null`。
